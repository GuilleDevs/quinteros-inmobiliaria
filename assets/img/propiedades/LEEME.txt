ESTA CARPETA YA NO SE USA
=========================

Las fotos de las propiedades ahora viven en Cloud Storage de Firebase,
no en el repositorio.

Cuando la inmobiliaria sube una foto desde el panel, el NAVEGADOR:

  1. la endereza si venía rotada (fotos de celular),
  2. genera dos versiones — 1600 px para la ficha, 640 px para las
     tarjetas del catálogo,
  3. las comprime,
  4. las sube a Cloud Storage.

Recién ahí viajan por internet, así que una foto de 6 MB del celular
sube unos 200 KB. Antes, con el backend PHP, se subía entera y la
achicaba el servidor.

La carpeta se conserva vacía solamente porque la versión anterior del
proyecto (etiqueta v1-php) guardaba las fotos acá. Si no pensás volver
a esa versión, se puede borrar sin problema.
